# 🌸 Elas por Aí — Landing Page (Em Construção)

Landing page oficial do projeto **Elas por Aí**, desenvolvida com **Next.js**, **Tailwind CSS** e hospedada na **Vercel** com domínio customizado em `elasporai.com`.

---

## 🚀 Tecnologias Utilizadas

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Linguagem:** TypeScript / JavaScript
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Hospedagem:** [Vercel](https://vercel.com/)
- **Gerenciamento de Domínio:** Squarespace (`elasporai.com`)

---

## 💻 Como Rodar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/elasporai/elasporai-landing.git](https://github.com/elasporai/elasporai-landing.git)
   ```
